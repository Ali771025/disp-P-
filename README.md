# Transition Matrix Powers

MATLAB exercise computing a transition matrix raised to the 100th power.

## Overview

The script defines a four-state transition matrix, computes its 100th power, and displays the result.

## Repository contents

- [LICENSE](LICENSE)
- [disp(P); .m](disp%28P%29%3B%20.m)

## Requirements

MATLAB-compatible matrix operations; no additional toolbox is evident from the source.

## Getting started

Clone this repository and open its directory:

```bash
git clone https://github.com/Ali771025/disp-P-.git
cd disp-P-
```

Run the example from that directory:

```matlab
run('disp(P); .m')
```

## Compatibility and scope

The `.m` source contains MATLAB matrix code even though GitHub may classify the repository differently. Taking a high matrix power is an illustrative calculation; convergence conditions should be considered when adapting it to other chains.
